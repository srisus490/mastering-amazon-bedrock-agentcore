🔄 Cache Buster - Fix AI Insights

⚠️ The Problem

Your browser has cached old JavaScript files. The AI Insights feature won't work until you clear the cache.

✅ Solution: Hard Refresh

Press Ctrl + Shift + R on Windows/Linux

Or Cmd + Shift + R on Mac

This forces your browser to reload all files from the server.

🚀 Quick Fix

  1. Click the button below to open the dashboard
  2. When the dashboard opens, immediately press Ctrl + Shift + R
  3. The AI Insights should now work!
Open Dashboard

🔍 Alternative: Incognito Mode

Open the dashboard in an incognito/private window:

  1. Press Ctrl + Shift + N (Chrome) or Ctrl + Shift + P (Firefox)
  2. Go to http://localhost:3000
  3. AI Insights will work without cached files

✓ How to Verify It's Fixed

After hard refresh, open browser console (F12) and look for:

  • ✓ "AIInsightsManager initialized" message
  • ✓ No "Cannot use import statement" errors
  • ✓ AI Insights section loads when you select a system

🛠️ Still Not Working?

Try these steps:

  1. Stop the server: Press Ctrl + C in the terminal
  2. Close all browser tabs with localhost:3000
  3. Restart the server: 
    cd web-dashboard
python -m http.server 3000
  4. Open fresh browser tab and go to http://localhost:3000
